# 지원 보드

채용 공고 캘린더 · 전형 일정 · 자소서 아카이브를 한 화면에서 관리하는 정적 웹앱.

## 쓰는 법

배포된 주소를 열고 **내 조건**에서 관심 직무와 기업 형태를 고르면, 조건에 맞는 공고만 보입니다.
지원할 공고에 **지원**을 누르면 `내 지원` 탭에 모이고, 서류 마감 D-day가 상단에 뜹니다.
서류 결과를 **합격**으로 바꾸면 그 다음 전형(AI 역량검사, 적성검사, 인적성검사, 1·2차·최종 면접)을
붙여 일정을 넣을 수 있고, 그 날짜가 캘린더와 주간 플래너에 함께 표시됩니다.

## 내 데이터는 어디에 있나

전부 **본인 브라우저(localStorage)** 에만 저장됩니다. 서버로 보내지 않고, 같은 주소를 열어도
다른 사람에게 보이지 않습니다. 저장되는 것: 지원 여부, 전형 일정, 공고별 자소서·이력서 본문,
경험 정리, 마스터 자소서·이력서, 주간 할 일.

브라우저 데이터를 지우거나 기기를 옮기면 사라집니다. **백업** 버튼으로 JSON 파일을 내려받아 두고,
다른 기기에서 **복원**으로 불러오세요.

## 공고 데이터

`data/jobs.json` 하나에만 들어 있습니다. 공개 정보(기업·직무·접수기간·역대 오픈 이력·출처·링크)만
담고 개인 메모는 넣지 않습니다. 이 파일이 갱신되면 모든 사용자가 자동으로 최신 목록을 봅니다.

- `confirmed: false` — 과거 접수 패턴으로 추정한 **예상** 일정
- `confirmed: true` — 실제 공고로 확인한 **확정** 일정
- `start`, `end`가 빈 문자열 — 상시·수시 채용

## 구조

```
index.html        앱 전체 (의존성 없음)
data/jobs.json    공고 데이터
```
